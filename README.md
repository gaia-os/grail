# GRAIL

_Graph Reasoning from AI Learning_

GRAIL aids users in constructing world models using Probabilistic Programming Languages (PPLs), 
but it is much more than just a wrapper around a PPL.

GRAIL is a neurosymbolic, AI-powered modeling framework that works with you during model creation, simulation, and statistical analysis.
Ultimately, it will also take things a step further with Active Inference methods to give targeted actions to reduce uncertainty, for better decision-making.

What's inside:

1. Tools to better track and manage your world models.
2. AI-powered world model construction as PPL scripts.
3. Navigation with AI through statistical analysis tools.
4. Active Inference policies that balance knowledge- and value-seeking actions.

## Version 0.X

For our first version, we are focusing on developing the set of tools and functions etc.
and setting aside agentic-orchestrator-type processes for now.

We are also setting aside model management and storing for now, leaving that to the external application.
However, we will provide the necessary I/O save/loading utils.
